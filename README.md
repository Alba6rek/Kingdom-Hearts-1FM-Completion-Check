# Kingdom Hearts 1 FinalMix  Completion Check

Site for reading and analyzing a Kingdom Hearts 1 Final Mix save file. Shows what remains to do for full 100% Game Completion, Achievements, Collectibles. Includes a designed Hint system.

This site Has been tested on the Windowds-Steam version only.

## Kingdom Hearts 1 FinalMix Save game locations

### Your Steam Cloud

If you have Steam Cloud enabled for KINGDOM HEARTS -HD 1.5+2.5 ReMIX-, you can download your save [directly from here.](https://store.steampowered.com/account/remotestorageapp/?appid=2552430), the save file name is "KHFM_WW.png". 
You can use this if you want to check your save progress without access to your PC (on mobile/tablet for example) or if you don't want to search manually for the save files.

### Windows - Steam

`%USERPROFILE%\Documents\My Games\KINGDOM HEARTS HD 1.5+2.5 ReMIX\Steam\`  
**Pro Tip:** Copy and paste this code into the folder path bar of the Windows File Explorer window and press Enter to go there instantly (Windows 10). You can also paste it inside the Run window (Windows key + R).  
*Example path: C:\Users\your-username\Documents\My Games\KINGDOM HEARTS HD 1.5+2.5 ReMIX\Steam\your-steamid*

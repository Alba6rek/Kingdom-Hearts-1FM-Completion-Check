# Minigame Subrecord Display

The Journal Minigames UI now expands the three grouped minigames into their
individual records.

## Jungle Slider

```text
Jungle Slider
  Green Serpent
  Splash Tunnel
  Jade Spiral
  Panic Fall
  Shadow Cavern
```

The save stores a top-five leaderboard for every Jungle Slider course, but the
completion tracker intentionally displays **only record #1** for each course.
The other four records remain decoded/preserved internally for research.

## Vine Jump

```text
Vine Jump
  Jump Course
  Trap Course
  Acrobatic Course
  Expert Course
```

Again, only leaderboard record #1 is displayed for each course.

## Olympus Coliseum

```text
Olympus Coliseum
  Phil Cup
  Pegasus Cup
  Hercules Cup
  Hades Cup
```

Each cup has one time-trial record in the save, so each child entry displays
that record or `No record`.

## 100 Acre Wood

The existing five individual minigames remain unchanged:

```text
Pooh's Hunny Hunt
Block Tigger
Pooh's Swing
Tigger's Giant Pot
Pooh's Muddy Path
```

This makes all Journal minigame categories use a consistent item-by-item
completion presentation.
